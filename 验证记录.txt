验证记录 — 搜看 1.0.0

构建与产物
- Android API 23+，targetSdk 34，无第三方运行依赖。
- APK 经 aapt/javac/d8/zipalign/apksigner 构建并通过签名验证；最终交付关闭 debuggable。
- 最终 APK 在 Android 11 模拟器成功安装并启动。
- WGT 与 APK 内资源来自同一个 web 目录，versionCode 100。

通过的检查
1. 实际 Java 下载器的 14 个 HTTP/JVM 续传用例，包括206、忽略Range、416、错误范围/总量/长度/编码、短包、超大包、换包、完整片段复用以及杀进程后恢复。
2. 实际 Java 包校验器的15个用例，覆盖有效包、哈希、截断、缺必要文件、越界路径、重复条目、展开大小和条目数量限制。
3. 原生更新生产方法的 JVM 夹具：并行最高版本选择、旧CDN不遮挡新版本、失效源、无校验拒绝、应用标识和最低外壳版本过滤、下载换源、Wi-Fi中断、目录恢复、未确认启动回退及成功确认保留。
4. Playwright：320/390/768/1280宽度无水平溢出，网页/夸克搜索，历史持久化，自定义来源和非法地址拒绝，文本安全渲染，手动/Wi-Fi更新状态，进度限制，更新重载，快捷入口及底部导航。
5. 真实Android instrumentation：HTTP版本检查、WGT下载/校验/安装、同进程显示新版、localStorage保留；随后发布有效哈希但脚本报错的包，15秒后回退，记录仍保留。测试采用本地夹具，不等于公网更新已发布。
6. 实际Android浏览器页：正确打开Google的夸克分享定向检索URL；外部WebView中typeof TVBridge为undefined。
7. 对YYAPP当前类和脚本的既有回归检查通过；补充复现旧资源备份过早删除及缺少解压上限的行为。未修改YYAPP跟踪文件。
8. 最终原生截图检查补齐旧WebView 83的flex gap/inset兼容间距及页面初始背景，避免白色闪屏。
