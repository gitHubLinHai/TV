搜看 v1.0.3 — 应用内网盘功能验证
日期：2026-10-28
工程：E:\myUnity\TV

这次实现
- 网页搜索仍默认夸克，普通网页在 APK 内置浏览页打开。
- 网盘模式不再跳转搜索网站：并行查询夸克盘搜和 PanSou，合并去重，只展示通过域名校验的夸克分享链接。
- 结果包含标题、来源、时间、已有提取码；没有结果和接口故障分开显示。
- 点击结果后在应用内浏览分享目录，支持多层文件夹、返回、更多文件、提取码重试。
- 可以直接粘贴夸克分享链接（可带提取码），打开目录，不需要搜索站收录它。
- 视频点击后使用夸克分享页实际提供的预览接口；网页预览有本地只读媒体代理，APK 使用原生 VideoView 播放，不是打开资源站网页。
- 会员完整播放路径：应用内登录夸克 → 返回文件操作面板 → 明确点击“转存这一个文件并完整播放” → 只转存所选文件到网盘根目录 → 查询转存任务 → 请求账号有权限的转码/原始播放地址 → 原生播放器。
- 转存不自动发生，不批量保存，不删除已有文件。播放位置保存在本机；预览和完整播放使用不同进度键。
- 网页预览不会接收账号 Cookie。APK 的搜索请求不发送夸克 Cookie；只有固定夸克接口和允许的夸克媒体域名可使用账号会话。

真实验证结果
1. 浏览器：真实搜索曾返回49个去重夸克分享（不同时间与来源可用性会变化，不是固定资源数量）。
2. 浏览器：打开真实分享，连续进入多个文件夹，成功播放120秒分享预览；整个过程留在本地页面，没有跳转搜索网站。
3. Android 11 模拟器：真实搜索返回30条；真实目录与文件夹读取成功；原生播放器开始播放，样本时长120047毫秒；返回后登录和完整播放按钮仍可用。
4. 浏览器夹具：验证来源合并、去重、恶意域名/HTML标题过滤、部分源失败、所有源失败、空结果、目录前进/返回、分享预览、显式单文件转存/任务轮询/账号播放流程，以及过时响应忽略。夹具测试不代表真实会员账号已验收。
5. 4种视口及原有网页搜索、历史、设置、热更新状态测试通过。
6. 实际Java包校验16个用例和更新源/目录恢复测试通过；新资源包必须包含js/netdisk.js。

待用户账号验证
未使用用户的会员账号；没有进行真实云端转存，也没有确认该账号下完整视频、全部编码格式、会员清晰度的播放结果。
本次真实视频测试是服务端提供的120秒预览，不是完整视频。任何完整播放都继续受夸克账号权限和平台接口限制。
公共搜索源可能超时、限流或调整接口，不能宣称全网覆盖。失效链接和需要提取码的分享会显示实际错误。

热更与安装
这次新增了原生网盘请求和播放器，外壳版本提升到2；需要先覆盖安装TV-v1.0.3.apk。仅替换网页资源无法让旧APK获得原生功能。
资源包和APK保存在release目录。本轮未推送或发布到远程；线上更新源尚未发布新包。
