在“短剧剧场 > 管理本地片库”粘贴 JSON 并导入。
仅接受 HTTPS 视频直链（例如 MP4、HLS m3u8）；网页地址和网盘分享地址不是视频直链。
当前没有默认片库，下面的 example.com 是格式占位，不能播放。

{
  "dramas": [
    {
      "id": "my-drama-1",
      "title": "你的短剧名称",
      "category": "都市",
      "heat": 100,
      "episodes": [
        {"title": "第 1 集", "url": "https://example.com/episode-1.mp4"},
        {"title": "第 2 集", "url": "https://example.com/episode-2.m3u8"}
      ]
    }
  ]
}

最多 200 部，每部最多 300 集。热门使用片库里的 heat 排序，不是红果实时热度。
无痕模式不允许导入或清空；已有片库可阅读/播放，不保存播放进度。
片库只保存在本机，卸载或清除应用数据会丢失；网页预览和 APK 不同步。
播放链接过期时重新导入有效片库。
