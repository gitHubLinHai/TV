搜看 — Android 私人搜索空间
工程位置：E:\myUnity\TV
应用包名：com.seagull.tv
最低 Android：6.0（API 23）；targetSdk：34。

已实现
- 默认夸克，支持百度、必应、搜狗、360、哔哩哔哩、腾讯视频、爱奇艺，Google 可选；APK 内独立浏览页打开搜索结果，网页预览同一标签页打开；网页返回、前进、刷新、复制链接、系统浏览器打开。
- 网盘模式通过夸克盘搜和PanSou取得结构化数据，结果和目录在应用内显示，不再跳转搜索站；输入分享链接可直接打开。
- 视频支持分享预览；登录后可明确选择单文件转存到网盘根目录，并请求账号有权限的完整播放地址。会员实测尚待用户登录。
- 自定义HTTPS搜索站模板只用于网页搜索模式。
- 夸克网页入口及本机 WebView Cookie 持久化；实际登录及会员播放尚未使用用户账号验收。
- 热搜趋势入口打开百度电视剧热榜；这里不是影视排行数据接口，也不是内置全网资源索引。
- 手机界面、搜索历史、设置、下载列表、网页视频全屏回调及横竖屏配置支持。
- 普通 HTTP 文件下载交给 Android DownloadManager；服务器支持范围请求、链接仍有效等条件决定实际恢复能力。未实现视频流抓取或网页文件格式万能预览。
- 本地资源 WGT 热更新，多源最高有效版本选择、包大小及 SHA-256 校验、包内 appId/版本/最低外壳版本校验。
- 热更下载片段与大小/哈希绑定；206/Content-Range 检查、忽略 Range 时从头覆盖、416 重试、断网和杀进程保留片段。
- 临时目录解压、路径及重复条目校验、4096 条目/32MiB 单条/64MiB 解压总量限制。
- 目录切换失败恢复；新版首页启动确认、15 秒失败回退，未确认启动时进程退出则下次启动回退；失败资源版本隔离，避免自动重复安装。
- 本地首页与外部网页隔离：外部 BrowserActivity 没有 TVBridge，不允许文件访问；外部登录信息不传给本地首页脚本。

本机构建
在 PowerShell 进入 E:\myUnity\TV，执行：
 python tools/build_apk.py
产物：release\TV-v1.0.22.apk。
直接使用已安装的 D:\SDK 与 Unity OpenJDK，无需下载 Gradle 依赖。
可通过 TV_ANDROID_SDK、TV_JAVA_HOME 指定其他工具链。
也提供 android-shell Gradle 项目；该路径需要 Gradle 8.2 兼容环境与 AGP 8.2.2。
签名文件保存在 .signing\tv-personal.keystore，默认是个人开发签名；已加入 .gitignore。请自行备份，后续覆盖安装必须保持同一签名。不会提交或发布该文件。
TV_DEBUG=1 用于本地测试，开启 debuggable 和 WebView 调试；交付 APK 已关闭调试。

热更打包与发布
 python tools/make_wgt.py --notes "本次更新内容"
自动增加资源 versionCode/补丁版本号，并更新资源引用 URL。
产物：release\version.json 和 release\TV-v版本.wgt。
首次初始化才使用 --no-bump。发布后的同版本资源包不要覆盖，应始终增加版本号。
更新地址来自仓库已配置的 origin：gitHubLinHai/TV 的 main/release，通过 Fastly jsDelivr、jsDelivr、GitHub Raw 三个地址检查。
目前仅本地生成包，未提交、未推送、未发布到远程；远程没有已发布版本，因此手机现在不会获得线上新资源包。需要把源码和 release/version.json、对应 WGT 发布到上述仓库，才能进行实际线上热更。CDN 传播可能延迟。
修改原生 Java、权限、包名或原生浏览器能力不能只发 WGT，必须重新构建 APK；不兼容原生接口的资源应提升 minShellVersion，并同步提升原生 SHELL_VERSION。

v1.0.4 搜索、播放和无痕
- 搜索并发接入 PanSearch、夸克盘搜、PanSou；公开索引会波动，不代表全网覆盖。来源拒绝关键词、来源超时与无结果分开显示，支持重试和直接粘贴分享。
- APK 改用 Media3 1.5.1，支持 HLS、内存预缓冲和网络错误重试。缓冲目标 20—60 秒，上限约 48 MiB，不启用磁盘视频缓存。开始播放目标 1 秒、卡顿后恢复目标 5 秒；实际行为受媒体片段、码率、容量和网络影响。
- 会员转码默认均衡，不自动优先 4K；可选流畅/均衡/高清。设置仅影响转存后的会员转码播放，预览由夸克接口决定。
- 首页右上角一键无痕，不读写播放进度、不保存新搜索，切换时清空当前输入和资源列表；保留普通模式原有记录。
- Android 9+ 无痕网页使用独立进程和 WebView 资料目录，关闭后清理独立 Cookie、存储和缓存。异常终止的残留在下次启动清理。普通登录资料不删除；无痕登录只保留本次会话。
- Android 6—8 不支持本实现的 WebView 隔离，无痕时不打开通用网页，仍可在内置网盘模块无痕搜索/播放。
- 无痕不允许创建系统下载记录、复制访问链接或跳转外部应用。云端主动转存仍是账号内写入，无痕不会撤销转存或删除云文件，也无法控制网站服务端记录。
- 网页预览只能控制本页面记录，不能开启宿主浏览器的系统无痕窗口；因此预览无痕时不跳转网页搜索。完整网页无痕须在 APK 使用。
- 原生壳版本提升为 3，WGT 的 minShellVersion=3；旧 APK 不应接收此资源包。
- 当前直接构建使用已安装的 Android 36 android.jar / build-tools 34，首次构建 tools/player_dependencies.py 从官方 Maven 下载固定版本依赖，缓存到 work/player-deps。已验证的构建入口是 python tools/build_apk.py；Gradle 入口未验收。
- 附带 AndroidX / Media3 / Guava / checker-qual 的第三方许可说明，位于 APK assets/third-party-notices.txt。
